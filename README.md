AI System Design Interviewer
This is a project I built to practise system design interviews.

Users can select a project, answer AI-generated questions, and check their marks.
Features
- Signup and login
- Select a system design project
- Generate interview questions using AI
- Submit answers
- Check interview marks
Tech Stack
- Frontend: React, JavaScript, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- Authentication: JWT
- AI: Groq API
Run Locally
